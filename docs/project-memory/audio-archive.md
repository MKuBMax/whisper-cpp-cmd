# 最近识别音频归档

为分析长语音识别失败和幻觉，App 将每次交给本地识别引擎的音频保存在 `audio-recordings/`，并为每段音频写一份 JSON 元数据。每条新记录最多有三份 WAV：录音刚停止时的原始麦克风音频、系统参考消除和 Processor 之后且服务端 VAD 之前的模型输入，以及用同一份 Silero VAD 参数物化出的语音片段音频。

## 当前行为

- 仅保存通过空录音保护、即将交给识别管线的录音；短录音、无效采样和数字静音不会归档。
- 每条 JSON 保存模型、语言、VAD、参考消除状态、预处理配置、各轨音频时长、VAD 段起止时间、trace id、识别文本和成功/失败状态；不保存转写 prompt 或术语表。
- 最多保留 10 个逻辑记录；每条记录的所有 WAV 和 JSON 一起清理。VAD 关闭或 VAD 导出失败时仍保留原始音频和模型输入，识别不会被归档诊断路径阻塞。
- App Support 中的归档目录和文件设为当前用户可读写。菜单栏“最近语音记录”子菜单列出最新条目；选择条目可分别试听原始音频、送入引擎的音频和 VAD 后音频，并查看识别文字。子菜单底部可以在 Finder 中打开目录并手动删除记录。
- 归档失败只记录 warning，不阻止识别。

默认 DEV App 和正式 App 的目录为 `~/Library/Application Support/WhisperCppCmd/audio-recordings/`；使用 `WHISPER_CPP_CMD_DATA_DIR` 时跟随该数据根目录。
