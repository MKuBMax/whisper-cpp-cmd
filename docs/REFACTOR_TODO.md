### 3. 验证按住录音、松开识别

- [ ] 用物理右 Command 测试短句、长句、快速轻触、连续多次录音和无声录音。
- [ ] 确认松开后立即停止本次采集，等待模型时不会继续把声音录入。
- [ ] 确认模型冷启动和释放资源后的首次录音，不丢开头、末尾，不重复启动模型进程。
- [ ] 识别过程中再次按键，不积压成稍后突然开始的新录音。
- [ ] 检查录音浮窗、识别中提示、完成/失败提示的切换；失败后没有残留提示，下一次仍能录音。
- [ ] 确认录音结束或失败后，其他媒体音量能够恢复。

完成标准：每次按住/松开只对应一次录音和一次最终结果，无卡住、重复输出或意外常驻录音。

### 4. 验证光标输入与剪贴板回退

| 场景 | 应有结果 | 状态 |
| --- | --- | --- |
| TextEdit 等原生输入框 | 最终文字插入一次，中文、标点、换行正常 | [ ] |
| 浏览器普通输入框与富文本编辑区 | 能确认可编辑目标时输入；无法确认时复制并提示 | [ ] |
| 实际常用编辑器、聊天软件、终端 | 分别记录是否输入成功或保守回退，不把已发按键当作已输入 | [ ] |
| 桌面、Finder、无输入框、密码框 | 不发送输入按键，文字复制到剪贴板并提示 | [ ] |
| 录音/识别途中切换 App 或输入框 | 不把文字误输到新目标，保留剪贴板副本 | [ ] |
| 同一输入框内移动光标或改变选区 | 检查当前目标比较是否足够；明确行为并排除误覆盖 | [ ] |
| 无声、失败或重新加载模型后复制最近结果 | 仍复制最近一次成功转录，不复制状态/错误文案 | [ ] |

完成标准：无误输入、重复输入、意外提交或未提示的结果丢失。对不完整支持 Accessibility 的编辑器，明确记录兼容性边界。
